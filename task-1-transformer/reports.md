# 任务一 · 实验总结

**训练方差与评估噪声是两回事。** 尽管准确率接近 90%,total loss 仍然偏大。同一模型在不同随机种子下,`hparams_accuracy.csv` 中的准确率落在 0.85–0.90 区间,最好结果为 0.9008。单纯增加模型深度有时反而会使准确率下降,但要在过拟合之前取得更好的效果,通常仍需要更深的模型。超参搜索后续可以改用随机采样(蒙特卡洛)或其他超参优化方法。

**mask 处理缺失会淹没信号。** 最初的 `TransformerClassifier.forward` 只在显式传入 causal mask 时才会屏蔽时间信息。最后一步改动是对 padding token 加 mask,避免无效 embedding 参与平均、把有效信号淹没。该改动使准确率从 0.68 提升到 0.8 以上。

**残差连接是否保留会影响收敛。** 在相同 seed、相同其余超参下,保留与去掉第一层 residual 构成干净对照:loss 26.30 → 51.99,准确率 0.9025 → 0.4933。去掉后模型无法有效收敛,基本没有分类能力,输出近似服从随机的二项分布采样。

**梯度裁剪的引入动因。** 本项目在 `train.py` 中使用 `clip_grad_norm_(model.parameters(), max_norm=1.0)`。这一处理是在参考他人做法后引入的,训练过程因此更稳定;但本轮未做"有 / 无裁剪"的对照实验来单独量化其贡献。

**已知疏漏。** Cosine schedule 的 `eta_min` 取默认相对值(约为初始学习率的 20%),`T_max` 取 epoch 数;这两个参数本可作为超参调节,但未纳入本轮超参搜索。
